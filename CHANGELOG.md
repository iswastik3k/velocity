## [1.0.0] — 2026-08-20

Initial release.

### Added

- Hyprland Lua config — Catppuccin Mocha Lavender, frosted glass decoration, custom animation curves
- Waybar — minimal labeled status bar, powerline clock, powermenu button
- Wofi — launcher and powermenu, no icons, frosted glass
- Kitty — JetBrainsMono Nerd Font, 0.88 opacity, lavender cursor
- Zsh + Zinit — autosuggestions, syntax highlighting, history substring search
- Starship — cold surface-to-accent powerline prompt
- Fastfetch — Catppuccin Mocha color overrides, lavender logo
- Hyprlock — blurred Hollow Knight wallpaper, large clock, minimal input field
- Hypridle — dim at 10 min, lock at 15 min
- Dunst — Catppuccin urgency levels, lavender normal border, red critical
- Yazi — HJKL keymap, Catppuccin theme, file type coloring
- Zen Browser — userChrome.css and userContent.css, Catppuccin Mocha Lavender
- GTK theme — Catppuccin Mocha Lavender
- Cursor — Catppuccin Mocha Lavender
- Icons — Papirus Dark
- SDDM — Catppuccin Mocha Lavender, Hollow Knight wallpaper
- install.sh — automated setup with backup, symlinking, and dependency installation
